## 1. Central Scientific Hypothesis

> **Hypothesis**: Training a fine-grained segmentation network on high-fidelity synthetic facial occlusions generated by latent diffusion models—with sub-pixel masks derived via attention thresholding and boundary refinement—significantly improves generalization and boundary precision ($\ge +5.0\%$ mIoU, $\ge +8.0\%$ mBIoU) on real-world in-the-wild occlusions compared to models trained on traditional 2D Cut-and-Paste synthetic data or limited real data alone.

---

## 2. Controlled Comparative Matrix

All models are trained with identical hyperparameters (SegFormer-B0, AdamW, $\text{lr}=6\times 10^{-5}$, 40 epochs) across 4 experimental conditions:

| Exp ID | Training Data Source | Volume | Annotation Technique | Testing Set | Target Metric (mIoU) |
| :---: | :--- | :---: | :--- | :--- | :---: |
| **EXP-0** (Real Lower-Bound) | Real-world occluded faces | 500 images | Manual annotations | RealOcc Test | Baseline ($\sim 0.58$) |
| **EXP-1** (Cut-and-Paste) | CelebA-HQ + COCO cutouts | 8,000 images | Direct 2D paste (RandOcc style) | RealOcc Test | $\sim 0.65$ |
| **EXP-2** (Proposed Method) | **Diffusion Synthetic Dataset** | 8,000 images | **Autonomous Attention + SAM** | RealOcc Test | **$\ge 0.72$** |
| **EXP-3** (Hybrid / Pretrained) | Diffusion Synthetic + Real Fine-tune | $8,000 + 500$ | Autonomous + Manual | RealOcc Test | **$\ge 0.76$** |

---

## 3. Unseen Test Benchmark Isolation

To guarantee scientific integrity:
1. **Zero Data Contamination**: No images from the test benchmark (RealOcc / FaceOcc test split) are ever exposed to the diffusion prompt conditioning, attention extraction, or training pipeline.
2. **Gold Standard Test Split**: Exactly 1,000 annotated real-world images from `data/real_eval/images/test` with ground-truth masks in `data/real_eval/masks/test`.
3. **Fixed Random Seed**: Global seed `seed = 42` locked across data loaders and model weight initialization.

## 4. Ablation Studies

To isolate the contributions of individual system components, three ablation series are scheduled:

### 4.1 Ablation A: Impact of Boundary Refinement Algorithm
- Condition A1: Raw inpainting guidance bounding box as mask ($M_{\text{guide}}$).
- Condition A2: Cross-attention map thresholding without refinement ($A_{\text{token}} \ge \tau$).
- Condition A3 (Full): Cross-attention map + SAM boundary snapping ($M_{\text{refined}}$).
- *Metric*: Measure Boundary IoU ($\text{mBIoU}$) across conditions.

### 4.2 Ablation B: Dataset Volume Scaling
- Train SegFormer-B0 on synthetic pools of size $N \in \{1,000, 2,500, 5,000, 8,000, 12,000\}$.
- Plot the scaling curve of mIoU vs. synthetic sample count.

### 4.3 Ablation C: Architecture Generalization
- Compare SegFormer-B0 (Transformer) against DeepLabV3+ (ResNet-50 CNN) to verify that synthetic data gains are architecture-agnostic.

## 5. Statistical Significance & Reporting Standards

1. **Multiple Runs**: Every primary experiment (EXP-0 through EXP-3) must be executed over 3 distinct random seeds ($42, 1337, 2024$).
2. **Reporting Format**:
   - Values presented as $\text{Mean} \pm \text{Std Dev}$.
   - Class-wise breakdown table for all 6 semantic classes.
   - Confusion matrix of predicted class vs ground truth.
3. **Artifact Logging**:
   - Metrics logged in standard JSON format: `experiments/{exp_id}/metrics.json`.
   - Qualitative prediction galleries (Input Image, Ground Truth, Predicted Mask, Error Heatmap) saved as `.png` visual artifacts.
